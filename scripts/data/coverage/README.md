# Coverage data

Boundary files for the regions covered by the roaming-coverage mask; read by
`scripts/update-mask.mjs` (see its header comment for provenance).

## germany.geojson

- Official BKG 1:250k Germany border, sourced via **geoBoundaries**
  (Federal Agency for Cartography and Geodesy).
- License: **Datenlizenz Deutschland – Namensnennung – Version 2.0**
  (govdata.de/dl-de/by-2-0). Attribution required.
